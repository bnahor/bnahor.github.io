When systems degrade, interface clarity matters as much as system throughput.

## Principles I use

- Show state transitions, not just static snapshots.
- Keep primary actions visible in one viewport.
- Avoid color-only severity signals.

```json
{
  "status": "degraded",
  "runbook": "https://example.com/runbook",
  "owner": "platform-oncall"
}
```

The best platform experience is one where on-call engineers can think clearly under pressure.
